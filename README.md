# 거축 기업 랜딩페이지

한국어, 딥 네이비, 비대칭 타이포그래피 중심의 반응형 정적 페이지입니다.

## 실행

Node.js로 아래 명령을 실행합니다. 의존성 설치는 필요하지 않습니다.

```sh
npm run build
npm start
```

브라우저에서 http://127.0.0.1:4173 을 엽니다. `dist/index.html`을 직접 열어도 페이지를 확인할 수 있습니다. 클립보드 권한이 없으면 직접 선택해 복사하는 입력창이 표시됩니다.

## 구성과 연결 상태

- `index.html`: 콘텐츠, 탐색 메뉴, 문의 유형, 채용 문의 진입점
- `style.css`: 네이비 테마와 반응형 레이아웃
- `tokens.css`, `base.css`: Hallmark 기반 토큰과 공통 스타일
- `app.js`: 모바일 메뉴, 문의 유형 선택, 문의 내용 복사
- `scripts/build.mjs`: 정적 배포 파일 생성
- `scripts/serve.mjs`: 로컬 미리보기

실제 고객사, 실적, 프로젝트 사례, 구체적인 채용 공고와 수신 주소는 제공되지 않아 넣지 않았습니다. 본문은 검토 가능한 소개 문구 초안입니다.

문의 버튼은 접수나 전송을 하지 않습니다. 작성한 내용을 클립보드에 복사하거나 수동 복사할 수 있도록 표시합니다. 입력 내용은 저장하거나 외부로 전송하지 않습니다. 실제 접수 기능을 추가하려면 수신 채널, 서버 접수 API, 개인정보 처리방침과 동의 방식이 필요합니다.

Pretendard와 Swiper v12는 CDN에서 불러옵니다. 히어로에는 Pexels의 무료 건축 사진 3장을 사용합니다. 출처는 푸터와 `assets/README.md`에 기록했습니다. 사진은 소개용이며 실제 시공 사례가 아닙니다.

히어로는 터치 스와이프, 이전·다음, 번호 표시, 자동 재생·일시정지를 지원합니다. 키보드 포커스 진입, 화면 밖 이동, 브라우저 탭 숨김 시 자동 재생이 멈춥니다. 동작 줄이기 설정에서는 자동 재생을 끄고 전환 시간을 없앱니다. Swiper 로딩 실패나 자바스크립트 비활성화 시 첫 이미지와 본문을 유지합니다. 외부 이미지와 라이브러리 사용에는 인터넷 연결이 필요합니다.

## 검증

히어로 변경 후 Hallmark 정적 검사: 0 FAIL, 1 WARN(외부 이미지 링크). Pexels의 무료 사용 허용 라이선스를 확인했으며 출처를 표기했습니다. JavaScript 구문 검사, 정적 빌드, 슬라이드 구성 및 자동 재생·동작 줄이기·CDN 실패 처리 로직 검증을 통과했습니다. 이미지와 Swiper는 외부 CDN 연결에 의존합니다.

현재 환경에 `puppeteer-core`가 없고 npm이 캐시 전용 모드이므로 자동 스크린샷과 실제 브라우저 동작 검증은 수행하지 못했습니다. 모바일 CSS는 작성했으며 실제 화면 검증은 미완료입니다.

Sites에는 비공개 프로젝트를 생성했으나 소스 준비 도구가 `Unable to prepare the Site.` 오류로 종료되어 배포되지 않았습니다. `.openai/hosting.json`에 동일 프로젝트 ID를 보존했습니다.
